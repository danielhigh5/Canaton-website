# Canaton Website

Static website for Canaton Trading Corporation.

## Files
- `index.html` – main website
- `styles.css` – design and responsive layout
- `script.js` – mobile navigation and dynamic footer year
- `images/` – reserved for future product and project images

## Deployment
This site is designed to be hosted on Cloudflare Pages or another static host.

## Important
The current version uses externally hosted placeholder architectural images. Replace them with Canaton's own product/project images before final commercial launch.
